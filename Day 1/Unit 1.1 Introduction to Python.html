Hello World¶

The first program that one writes in any language is typically the "Hello world!" program, which simply prints "Hello world!" on the screen. In Python, this program is very simple and needs just one line:

print("Hello world!")

The program just calls the print function with the character sequence (string) "Hello world!" as argument.

Python files end with the .py extension. Technically, py files are text files and can be opened in any text editor. Some even recognize it as code and will turn on syntax highlighthing. You probably noticed that when we used print(), we put "Hello world" inside the parentheses, that’s what we want Python to show on the screen. The things inside the parentheses are called arguments — they are like pieces of information we give to print() so it knows what to do (in this case what to print).

Don’t worry about exactly how print() works inside — we’ll talk about how functions work in detail tomorrow. For now, just remember: print() is a special tool built into Python to show output, and it can take one or more pieces of information — separated by commas — and show them together.

Sequential Execution¶

If we want our program to greet not only the world, but for example also the Netherlands and especially Utrecht, we can add more statements to the program, like this:

In [5]:
print("Hello World!")
print("Hello Netherlands!")
print("Hello Utrecht!") 

Hello World!
Hello Netherlands!
Hello Utrecht!

Note here that Python is an interpreted language. That means that Python programs are executed directly by an interpreter, which runs the program line by line. This is in contrast to compiled languages, which need to be translated into another representation before being executable.

Comments¶

It is good practice (and really good idea!) to include comments in your program that explain what is happening ("Code tells you how, comments should tell you why."). Comment lines in Python start wish a hash (#). They are ignored by the interpreter during execution, but can be very helpful for you or another person trying to understand the code, especially when it does more complicated things. Make commenting your code a habit directly from the beginning, even if it feels unnecessary for the simpler first examples.

A comment is a note you write in your code for humans to read — not the computer.
Python ignores comments when it runs your program.

Example:

In [6]:
#greet the world
print("Hello World!")

#greet the Dutch
print("Hello Netherlands!")

#greet the people of Utrecht
print("Hello Utrecht!") 

Hello World!
Hello Netherlands!
Hello Utrecht!

The output of this program is still the same as before.

Literal Constants¶

A literal constant is just a fixed value that we write directly into our code.
It’s a value that doesn’t change — it’s literally what it is.

The string “Hello world!” (can also be written as ‘Hello world!’, i.e., with single quotation marks) from the above example is a so-called literal constant. Literal because its value is used literally (exactly as it is written in the program code), and constant because it just represents itself and cannot be changed during runtime.

In the same way also numbers can be literal constants in a program, for example 42 or 3.14, but more on numbers later.

Basic data types¶

Python has a few basic data types we are going to use all the time. These types tell Python what kind of data you’re working with.

The most common data types are:

  • Strings (str) → Text (characters, words, sentences)
    Examples: "Hello", 'Python', "123" (even though it looks like a number, it’s text if in quotes)

  • Integers (int) → Whole numbers
    Examples: 5, -2, 42

  • Floating-Point Numbers (float) (Numbers with decimals) Examples: 3.14, 0.5, -7.2

  • Boolean (bool) → True or False values
    Examples: True, False (These are useful for making decisions in your code)

Most languages share the same basic idea of data types — so once you understand these, it’s easy to learn another language later!

Strings¶

Strings (sequences of characters, including white spaces and other sorts of special characters) are one of the basic data types in Python. Strings can be denoted by using single quotes as well as double quotes, which work exactly the same way.

A string is just text — any sequence of characters inside quotes. You can use single quotes ' ' or double quotes " ". Just make sure they match!

In [7]:
print('Hello')
print("Hello")

Hello
Hello

Triple single or double quotes can be used to specify multi-line strings, which can be convenient when dealing with longer pieces of text. For example, the following code again produces the same output as above:

In [8]:
print("""Hello World!
Hello Netherlands!
Hello Utrecht!""") 

Hello World!
Hello Netherlands!
Hello Utrecht!

A single backslash at the end of a line is used to indicate that the string is continued in the next line, but without adding a newline. For example:

In [9]:
print("Hello World! \
Hello Netherlands! \
Hello Utrecht!") 

Hello World! Hello Netherlands! Hello Utrecht!

The function print can also take more than one arguments, seperated by a comma. For example:

In [10]:
print("Hello World!", "Hello Netherlands!", "Hello Utrecht!") 

Hello World! Hello Netherlands! Hello Utrecht!

Clearly, if you use a quotation mark to indicate the beginning and the end of a string, you cannot just use the same character within the string itself, as it would be interpreted as the end of the string.

For these cases, there are so-called escape sequences, beginning with the backslash character , which change the standard interpretation of the character(s). For example, to print the sentence It’s called “Python” correctly, the following code can be used:

In [11]:
print("It's called \"Python\".") 

It's called "Python".

or

In [12]:
print('It\'s called "Python".') 

It's called "Python".

Some other frequently useful escape sequences are \\ for including a backslash in a string, \n for a newline and \t for a tab.

Numbers¶

Python knows basically two types of numbers: integers (whole numbers) and floating point numbers, or floats for short (such with a decimal point). For example:

In [13]:
print(42)
print(3.14)

42
3.14

Note that in this example, the numbers are again literal constants.

Arithmetic Expressions¶

Python supports seven basic operators for working with numbers:

** (power, exponentiation)
*  (multiplication)
/  (division)
// (integer division)
%  (remainder, modulo)
+  (addition)
-  (subtraction)

The order of expressions is the same as you know it from mathematics (exponents: **, then multiplication, division, floor division, modulo: *, /, //, % and finally addition and subtraction: +, -), and like there you can also use parentheses to structure more complex expressions.

For example:

In [14]:
# do some random arithmetics
print("2 + 2 is", 2 + 2)
print(10 * 2, "is the result of 10 * 2.")
print("10/6 is", 10 / 6, "and 10//6 is", 10 // 6) 

2 + 2 is 4
20 is the result of 10 * 2.
10/6 is 1.6666666666666667 and 10//6 is 1

Interestingly, the + (addition) and * (multiplication) operators are also defined for strings, where they function as concatenation and repetition operators, respectively:

For example:

In [15]:
# string concatenation
print("Hello " + "world!")

# string repetition
print("Hello! " * 3) 

Hello world!
Hello! Hello! Hello!
